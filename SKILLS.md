# SKILLS.md

## Purpose

This document records the development tools, frameworks, and AI-assisted skills used while building the Movie Ticket Booking System.

## Development Skills and Tools

| Skill / Tool | How It Was Used |
|---|---|
| Spring Initializr | Generated the initial Spring Boot Maven project and dependency configuration. |
| Java 21 | Main programming language for the backend application. |
| Spring Boot | Built REST APIs, dependency injection, request validation, scheduling, and configuration. |
| Spring Web | Created REST controllers and HTTP endpoints. |
| Spring Data JPA | Implemented database persistence, repositories, and transaction management. |
| PostgreSQL | Stored users, theaters, shows, seats, holds, bookings, payments, and refunds. |
| Flyway | Created version-controlled database migrations. |
| Spring Security | Implemented basic access control for ADMIN and CUSTOMER users. |
| JUnit 5 | Wrote unit tests for pricing, discounts, refunds, and business rules. |
| Mockito | Mocked dependencies in unit tests where needed. |
| Git and GitHub | Version control, commit history, and source-code submission. |
| AI coding assistant | Helped analyze requirements, create implementation plans, identify edge cases, review code, and propose test cases. |

## AI-Assisted Development

AI assistance was used for:

- Understanding the assignment requirements.
- Planning the database entities and REST API structure.
- Identifying critical edge cases, including seat-hold expiry and concurrent booking attempts.
- Reviewing code structure and error handling.
- Proposing unit and integration test cases.
- Drafting documentation.

All AI-generated suggestions and code were reviewed, modified where needed,
tested, and validated by the developer before inclusion in the final project.
